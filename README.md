# 百日回归

《百日回归》是一款在浏览器里玩的单人交易策略游戏。你带着 1,000 万元现金进入市场，要在 100 个自然日内还清 1 亿元旧债。18 只虚拟股票、6 个 AI 游资席位和普通资金在同一个订单簿里交易。挂出去的单子可能只成交一部分，买入的股票要等到下一个交易日才能卖。

![《百日回归》雨夜封面](public/art/cover.png)

## 本地试玩

安装 Node.js 22 和 npm 后，在项目根目录运行以下命令，即可启动开发服务器。

```sh
npm ci
npm run dev
```

在浏览器打开 [本地交易室](http://127.0.0.1:5173)。从漫画序章进入交易室后，前两个交易日的引导会带你完成第一笔买卖。重新打开同一浏览器、同一地址即可继续上次的进度。

## 存档和测试

界面使用 React、TypeScript 和 Vite。Express 后端负责撮合订单、记账和推进模拟时间。服务器把每局的市场快照写入 `data/`，通过浏览器的会话 Cookie 识别存档。自托管时请持久保存这个目录，并让一个服务进程负责写入。

可以用一笔成交检查读档行为。在交易室记下成交后的现金、持仓和成交记录，关掉标签页，再用同一浏览器打开。三处应与关页前一致。服务端自动化测试还覆盖重复下单、服务重启后的存档恢复和写入失败时的账本回滚。

```sh
npm test
npm run build
```

## 自托管

构建完成后运行 `npm start`，即可在 [本地服务](http://127.0.0.1:5174) 访问游戏。也可以在安装了 Docker Compose 的机器上运行 `docker compose up --build -d`。Compose 会把存档放在名为 `game-data` 的卷里。
